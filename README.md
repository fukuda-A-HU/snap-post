# SnapPost

ショートカット 1 つで、設定したアプリのウィンドウだけを撮影します。PNG を保存し、画像をクリップボードにコピーしてから、ハッシュタグ付きの X 投稿画面を開きます。

Windows 11 向けの Flutter デスクトップアプリです。設定ウィンドウを閉じても終了せず、通知領域（システムトレイ）に残ります。

## 前提条件

- Flutter SDK（stable チャンネル、Windows デスクトップ有効）
- Visual Studio 2022 のワークロード「Desktop development with C++」

## 開発

```bash
flutter pub get
flutter run -d windows
```

## リリースビルド

```bash
flutter build windows --release
```

実行ファイル:

```text
build\windows\x64\runner\Release\snap_post.exe
```

同じフォルダの DLL と `data` も一緒に配布してください。

## 使い方

1. アプリを起動すると設定画面が開き、通知領域にアイコンが出ます。
2. 「更新」で見えているトップレベルウィンドウの一覧（タイトルと実行ファイル名）を読み、対象を選びます。選択は実行ファイル名と、任意のタイトル部分一致で保存されます。再起動後も、その条件に合うウィンドウを探します。
3. ショートカット（初期値は Ctrl+Shift+S）、ハッシュタグ、任意の固定テキスト、保存フォルダ、「Windowsの起動時に自動で起動する」を設定して「保存」します。ツリーにつなぐときは「つなげるツイート」も設定します。
4. 「まとめて投稿する（最大4枚）」がオン（初期値）のとき、撮影ショートカットは画像を投稿待ちに追加します。通知は「2/4枚 たまりました」のように枚数を示します。4枚目で自動的に投稿します。オフのときは、これまで通り1枚で投稿画面を開きます。
5. まとめて投稿するときは、まとめて投稿のショートカット（初期値は Ctrl+Shift+D）、トレイの「まとめて投稿」、または「投稿待ち」画面の「投稿画面を開く」を使います。
6. 1枚ずつのときは PNG を保存フォルダ（空欄なら `%USERPROFILE%\Pictures\SnapPost\yyyyMMdd_HHmmss.png`）に書きます。まとめて投稿するときは、その下の `yyyyMMdd_HHmmss` フォルダにその回の画像をまとめます。
7. 1枚のときは画像をクリップボードに入れ（CF_DIB と PNG）、ブラウザで X の投稿画面を開きます。通知は「画像をコピーしました。投稿画面で Ctrl+V で貼り付けてください」です。
8. まとめて投稿するときは、待っている画像ファイルをまとめてクリップボードに入れ（CF_HDROP。コピーとして貼れるようにします）、そのフォルダをエクスプローラーで開き、投稿画面を開きます。通知は「4枚をコピーしました。投稿画面で Ctrl+V で貼り付けてください（貼れない場合は開いたフォルダからドラッグ）」の形です。開いたあとに投稿待ちは空になります。
9. 対象ウィンドウが見つからないときは通知して終了します。クラッシュはしません。
10. 設定ウィンドウを閉じるとトレイに残ります。終了はトレイの「終了」か設定画面の「終了」です。すでに起動しているときに、もう一度起動すると、新しいウィンドウは出さず、動いているほうの設定画面を前面にします。

設定は `%APPDATA%\SnapPost\settings.json` に保存します。設定ファイルがまだないときのハッシュタグは `#VR活動報告大会2026 #NUMA` です。

ハッシュタグは `#` 付きでも無しでも入力でき、`#tag` をスペース区切りに正規化します。

撮影は、前面にないウィンドウでも `PrintWindow`（`PW_RENDERFULLCONTENT`）を優先します。失敗したときは、そのウィンドウの画面上の範囲を撮ります。どちらも DWM の拡張フレーム境界で影を切り抜きます。GPU 描画のウィンドウ（Unity / VRChat など）は、Windows の `PrintWindow` が合成結果を返せる範囲で撮れます。

自動起動をオンにすると、サインイン時は `--hidden` でトレイだけ起動します。

## まとめて投稿

初期状態では「まとめて投稿する（最大4枚）」がオンです。撮影のたびに PNG が投稿待ちに入ります。トレイの「投稿待ち」で、撮った順のサムネイル、1枚ずつの削除、「全部消す」、「投稿画面を開く」を使えます。投稿するときもこの画面を自動で開きます。

投稿時は、Chrome や Edge の投稿欄で Ctrl+V すると最大4枚を一度に添付できます。貼れない場合は、開いたフォルダから画像をドラッグしてください。

オフにすると、撮影のたびに1枚をビットマップとしてコピーし、すぐに投稿画面を開きます。

## ツリーにつなげる

X の intent URL は、スレッドの末尾を API なしでは探せません。つなぎたいツイートの URL（`x.com` または `twitter.com` の `/status/<id>`。クエリ文字列は無視します）か、数字だけの status id を「つなげるツイート」に貼ります。欄の下に読み取った id か、読めない旨が出ます。

「ツリーにつなげる」がオンで、id が有効なときだけ、投稿画面は次の形になります。

```text
https://x.com/intent/post?in_reply_to=<id>&text=...
```

投稿したあとは、そのツイートのリンクをコピーし、トレイまたは設定画面の「つなげる先を更新」を押します。クリップボードの URL から id を読み、次の返信先として保存します。これを繰り返すと、自分で末尾を指定しながらツリーを続けられます。

## X の投稿画面について

X の intent URL（`https://x.com/intent/post?text=...`）は画像を添付できません。画像はクリップボードに入っているので、開いた投稿画面で Ctrl+V して貼り付けてください。
