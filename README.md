# SnapPost

設定したアプリのウィンドウだけを撮影し、選んだ画像をクリップボードにコピーしてから、ハッシュタグ付きの X 投稿画面を開きます。

Windows 11 向けの Flutter デスクトップアプリです。ウィンドウを閉じても終了せず、通知領域（システムトレイ）に残ります。

## 前提条件

- Flutter SDK（stable チャンネル、Windows デスクトップ有効）
- Visual Studio 2022 のワークロード「Desktop development with C++」

## 開発

```bash
flutter pub get
flutter run -d windows
```

## リリースビルド

```bash
flutter build windows --release
```

実行ファイル:

```text
build\windows\x64\runner\Release\snap_post.exe
```

同じフォルダの DLL と `data` も一緒に配布してください。

## 使い方

1. アプリを起動するとメイン画面が開き、通知領域にアイコンが出ます。
2. 「更新」で見えているトップレベルウィンドウの一覧（タイトルと実行ファイル名）を読み、対象を選びます。選択は実行ファイル名と、任意のタイトル部分一致で保存されます。再起動後も、その条件に合うウィンドウを探します。
3. 右上の歯車から設定を開き、対象ウィンドウ、ハッシュタグ、任意の固定テキスト、保存フォルダ、「Windowsの起動時に自動で起動する」を保存します。
4. メイン画面の「撮影」で、選んだウィンドウをすぐに撮影して一覧へ追加します。対象が未設定か見つからないときは、ボタンの下に理由と「ウィンドウを選ぶ」が出ます。
5. 一覧は撮った順です。サムネイルを押すと大きく見られます。各画像の「投稿に使う」は同時に4枚までです。5枚目以降はチェックが外れます。不要な画像は「削除」でファイルごと消します。
6. 「投稿画面を開く」は、チェックした画像だけをクリップボードへ入れ、その画像だけのフォルダをエクスプローラーで開き、X の投稿画面を開きます。1枚のときはビットマップもコピーします。その後「投稿に使った画像をリストから外しますか？」と聞きます。はいなら一覧から外しますが、ファイルは残します。
7. ウィンドウを閉じるとトレイに残ります。トレイは「ウィンドウを開く」と「終了」です。すでに起動しているときに、もう一度起動すると、新しいウィンドウは出さず、動いているほうのウィンドウを前面にします。

設定は `%APPDATA%\SnapPost\settings.json` に保存します。設定ファイルがまだないときのハッシュタグは `#VR活動報告大会2026 #NUMA` です。

ハッシュタグは `#` 付きでも無しでも入力でき、`#tag` をスペース区切りに正規化します。

撮影は、前面にないウィンドウでも `PrintWindow`（`PW_RENDERFULLCONTENT`）を優先します。失敗したときは、そのウィンドウの画面上の範囲を撮ります。どちらも DWM の拡張フレーム境界で影を切り抜きます。GPU 描画のウィンドウ（Unity / VRChat など）は、Windows の `PrintWindow` が合成結果を返せる範囲で撮れます。

自動起動をオンにすると、サインイン時は `--hidden` でトレイだけ起動します。

## 撮影と投稿

起動するとメイン画面が開きます。撮影した PNG は保存フォルダ（空欄なら `%USERPROFILE%\Pictures\SnapPost`）に `yyyyMMdd_HHmmss.png` で残ります。投稿するときは、選んだ画像だけを `yyyyMMdd_HHmmss` フォルダへコピーしてから開きます。

複数枚はファイル一覧（CF_HDROP）としてコピーするので、Chrome や Edge の投稿欄で Ctrl+V するとまとめて添付できます。1枚のときはビットマップも入るので、従来どおり貼れます。貼れない場合は、開いたフォルダからドラッグしてください。

カウンターの「選択中 2/4」は、一覧の枚数ではなく、投稿にチェックした枚数です。

## ツリーにつなげる

X の intent URL は、スレッドの末尾を API なしでは探せません。メイン画面の「投稿画面を開く」のすぐ上に「ツリーにつなげる」欄があります。ツイート URL か数字の id を入力すると、その場で「status id: ...」か「読めません」と出ます。読めた内容は自動で保存されます。「クリップボードから貼り付け」と「クリア」、「開く」（ブラウザでそのツイートを確認）もあります。

欄が空、または読めないときは、ふつうの投稿画面を開きます。有効なつなげる先があるときは、いつも次の形になります。

```text
https://x.com/intent/post?in_reply_to=<id>&text=...
```

## X の投稿画面について

X の intent URL（`https://x.com/intent/post?text=...`）は画像を添付できません。画像はクリップボードに入っているので、開いた投稿画面で Ctrl+V して貼り付けてください。
